FOREVER MACRO CREATOR 1.0.0
For World of Warcraft: Forever 1.60.1 (Interface 16001)

INSTALLATION
1. Close World of Warcraft.
2. Extract the ZIP.
3. Copy the ForeverMacroCreator folder into:
   World of Warcraft\_classic_beta_\Interface\AddOns\
4. Confirm this file exists:
   ...\Interface\AddOns\ForeverMacroCreator\ForeverMacroCreator.toc
5. Start WoW and enable Forever Macro Creator on the AddOns screen.

HOW IT WORKS
- Open Blizzard's Macro window normally.
- Forever Macro Creator opens automatically beside it.
- Choose a class, then choose a color-coded category.
- Click a macro to preview its code.
- Click INSERT INTO BLIZZARD to place the code into the selected Blizzard macro.
- Click SELECT CODE and press Ctrl+C if you prefer manual copy and paste.
- The search box searches every class and category, so searches such as
  "Mocking Blow" work even when another class is selected.

FEATURES
- Dark, clean interface inspired by professional auction-house addons.
- Libraries for every original Classic class.
- Melee, ranged, ability, defensive, healing, control, utility, pet,
  form, totem, targeting, potion, and consumable categories.
- Spell and item icons beside each result.
- Class colors and category colors throughout the interface.
- Mouseover healing, focus control, stopcasting, pet, and targeting macros.
- Automatically discovers learned spells from the current character's spellbook.
- Adds potions and common combat consumables to every class library.
- 255-character macro counter.
- Automatic left-side fallback when there is not enough room on the right.
- Addon-compartment support for HidingBar and compatible addon launchers.

IMPORTANT
World of Warcraft does not allow addons to write directly to the operating
system clipboard. SELECT CODE highlights the complete macro so Ctrl+C can copy
it. INSERT INTO BLIZZARD writes directly into Blizzard's selected macro editor.
Create or select a Blizzard macro before using the insert button.

COMMANDS
/fmc
/fmc show
/fmc hide
/fmc auto
/fmc left
/fmc right
/fmc auto-side
/fmc scale 0.70-1.30
/fmc reset

Some equipment macros contain placeholders. Replace those placeholders with
the exact names of your own weapon and shield before using the macro.
